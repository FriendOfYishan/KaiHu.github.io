# 40-S最终实验汇总

**结论：CIFAR-10上，40-S与AdamW准确率接近，状态约减半；SGD准确率最高。30M FineWeb-Edu上，混合版明显改善40-S，但本次固定token预算下仍落后AdamW。**

49次运行全部完成：28次完整日程选参、21次确认，0次失败。实际总耗时6.06小时，12小时是上限，未为用满时间追加训练。确认种子22/33/44；以下±为三个种子的样本标准差。

40-S相对AdamW准确率均值高0.117个百分点，配对差95% t区间为[-0.568,+0.802]个百分点；3个种子中2个更好，不能据此宣称稳定准确率优势。完整40-S的测试交叉熵在三个种子都更低；混合版测试交叉熵高于AdamW。SGD同时有更高准确率和更低测试交叉熵，不将40-S称为本任务整体最优。

完整40-S状态减少49.85%，峰值减少4.75%，训练时间减少2.48%。混合版对应49.93%、4.76%、3.18%。小幅时间差没有额外计时重复，不外推为普遍吞吐优势。

完整40-S相对AdamW验证NLL高0.12510，配对95% t区间[+0.08692,+0.16328]；混合版高0.04561，区间[+0.03279,+0.05843]。两版三个种子都落后。混合版相对完整40-S缩小约63.54%的验证NLL差距。

完整40-S状态减少49.97%，峰值减少3.56%，训练时间减少1.62%；混合版状态减少36.03%，峰值减少2.59%，训练时间减少0.28%。混合版确实计入了嵌入、输出和向量参数的AdamW状态。

训练probe同样落后AdamW，当前差距首先包含优化不足，不能全解释为泛化差。该结果只适用于此模型、数据、配方及约5100万token的早期训练预算。它不否定所有Transformer上的可能收益，也未建立超过AdamW的非凸复杂度或验证质量优势。

## 解释与论文定位

这次确实观察到任务依赖：40-S在图像分类上达到与AdamW接近的准确率并节省状态；在正式网页语料的30M语言模型上，参数角色分工改善质量。当前最有依据的定位是低状态、质量接近的折中候选，尚不能写成已全面超过AdamW。

A/B的条件机制证据与本次两个真实任务结果分别保留。相同统计结构未必覆盖所有参数角色；新40-S同时改变了门控、动量对象、慢残差统计、偏差修正与分组，当前两任务实验不单独识别每项改变的因果贡献。

## 口径

CIFAR训练/验证为45000/5000张，测试为官方10000张，训练评估覆盖完整45000张。语言验证/测试各固定262144 token估计，训练probe为65536 token。测试不选参；候选均在独立种子11上做4次完整日程选参。混合版回退使用同任务AdamW独立选参配置。

状态/工作区与完整allocated峰值分开报告；训练时间包含取批、前反向、裁剪与更新，排除评估、初始化及数据准备。总体6.06小时包含任务流程开销。配对区间为df=2的小样本参考，未做多重比较校正。原始记录位于runs/，配置见FROZEN_PLAN.json与selected.json。
