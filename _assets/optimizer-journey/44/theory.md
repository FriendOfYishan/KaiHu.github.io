# 候选44：历史残差定尺度，归一化后积累更新动量

2026-11-16。仅依据工作区39、40理论和43实验推导；未联网、未调用子智能体，尚未实验。本文不宣称算法已超过AdamW，也不宣称外部文献意义上的首创。

## 出发点

43的语言模型训练probe NLL为5.08830，AdamW为4.99861；验证NLL分别为5.26597、5.20429。这首先暴露同预算优化不足，尚不能归因于纯粹的泛化不足。来源：experiments/20261115_candidate43_1h/FINAL_SUMMARY_ZH.md。

43使用当前梯度形成当前分母，之后对原始动量做非线性归一化。即便梯度无偏，归一化后的方向也未必无偏。例如首步M=q=0，标量随机梯度以1/3概率取2、以2/3概率取-1，其均值为0。43首步方向为g/sqrt((1+beta)g^2+epsilon^2)，期望严格为负；epsilon趋于0时为-1/(3 sqrt(1+beta))。这个例子说明有界更新本身不足以给出无偏下降证明，并不单独证明43必不收敛。

44将统计预测器与更新动量分离：历史统计确定尺度；当前梯度先按该尺度归一化，再进入更新动量。低精度误差只影响未来尺度选择，不直接注入参数更新方向。

## 完整定义

参数theta属于R^d。将各参数张量分别展平，预先划分不跨张量的连续组I_b，每组最多1024个坐标；n_b=|I_b|，b(i)表示坐标i所在组。尾组只平均有效坐标。

状态：S属于BF16^d，保存原始梯度的统计EMA；U属于FP32^d，保存归一化梯度的更新EMA；q属于FP32^B，保存每组残差平方EMA。全部零初始化。Q表示逐坐标确定性BF16舍入；所有计算先转FP32，只有写S时舍入。

参数：beta=0.9，rho=0.999，epsilon=1e-8，正尺度界a=1e-3、H=1e4，满足a<=1<=H。它们是首个待验证配置，不是已选出的最优配置。eta>0为固定学习率；学习率依训练时长T选择。以下定理对应固定eta、无梯度裁剪、无额外解耦权重衰减。若研究正则化，将其明确纳入F及其梯度。

第t步，当前参数为theta_(t-1)，g_t为在该参数上采样的随机梯度。

1. t=1时A_t=I；t>=2时，使用尚未更新的S、q：

   s_i=S_(t-1,i)/(1-beta^(t-1)), r_b=q_(t-1,b)/(1-rho^(t-1))，

   A_(t,ii)=clip((s_i^2+r_b(i)+epsilon^2)^(-1/2), a, H)。

   A为对角算子，不实际分配矩阵或持久向量。修正因子补偿零初始化权重；不把舍入后S称为严格无偏估计。

2. U_t=beta U_(t-1)+(1-beta) A_t g_t。

3. theta_t=theta_(t-1)-eta U_t。

4. q_(t,b)=rho q_(t-1,b)+(1-rho) beta/n_b sum_(i in I_b)(g_(t,i)-S_(t-1,i))^2。

5. S_t=Q(beta S_(t-1)+(1-beta)g_t)。

q更新必须使用旧S。A仅使用旧状态，即使实现时在读取g之后计算A也不改变这一要求。U不做偏差校正。S、U具有不同单位与用途，不能合并或相互替代。

每步一次梯度；无额外前向、反向、矩阵分解或全局排序。融合实现的持久状态为6d+4B字节，对比两份FP32向量的8d，节省25%-B/(2d)，组长1024时约24.95%。这不等于整机峰值显存减少25%，也不证明墙钟优势。

## 一般光滑非凸保证

假设F下有界F_*，且梯度L-Lipschitz。以采样前历史为条件，E_t[g_t]=f_t=grad F(theta_(t-1))，E_t||g_t-f_t||^2<=sigma^2。无凸性、PL条件、残差衰减条件或梯度统一有界假设。

A_t由历史确定，aI<=A_t<=HI，因此E_t[A_t g_t]=A_t f_t。这一性质不要求S、q准确，不要求BF16舍入无偏。

令kappa=beta/(1-beta)，Delta=F(theta_0)-F_*，

D_t=E[f_t^T A_t f_t]，V_t=E||A_t(g_t-f_t)||^2，Vbar=T^(-1) sum V_t。

若eta<=min{1/(4LH),1/(2 sqrt(2) LH kappa)}，则

    (1/T) sum E||f_t||^2
    <= 2 Delta/(a eta T) + (L eta+2 H L^2 eta^2 kappa^2) Vbar/a.          (1)

其中Vbar<=H^2 sigma^2无需额外结构假设即可成立。取eta=min{eta_0,c/sqrt(T)}，c>0固定，得到O(T^(-1/2))的平均梯度平方界。等价地，均匀抽取一个已访问迭代点获得该期望平稳性保证；不是非凸全局最优保证，也不是每步损失单调保证。

证明直接复用并适配工作区40第5节的可预测输入动量论证，不能将这个已有证明本身包装成新贡献：

设z_t=theta_(t-1)-eta kappa U_(t-1)。代入递推精确得到

    z_(t+1)-z_t=-eta A_t g_t。

令delta_t=grad F(z_t)-f_t。由光滑性、可预测性和A_t^2<=H A_t，

    E[F(z_(t+1))-F(z_t)]
    <= -eta(3/4-LH eta/2)D_t
       +H L^2 eta^3 kappa^2 E||U_(t-1)||^2 + L eta^2 V_t/2。

这里使用|delta^T A f|<=f^T A f/4+delta^T A delta，以及||delta_t||<=L eta kappa ||U_(t-1)||。

由EMA权重非负且总和不超过1、U_0=0，交换有限求和得到

    sum E||U_(t-1)||^2 <= sum E||A_t g_t||^2 <= sum(H D_t+V_t)。

累加光滑下降式，步长条件保证D项系数至少eta/2；利用D_t>=a E||f_t||^2和F(z_(T+1))>=F_*，得到(1)。证毕。

若用轨迹有效常数alpha>=a满足sum D_t>=alpha sum E||f_t||^2，可将(1)中a替换为alpha。主导复杂度常数与Vbar/alpha^2有关；仅将所有尺度同时缩小不会改善这个比值。44的机制目标是改善统计和更新方向的分离，使该常数及实测质量改善，而不是将其改善当作前提后宣称已证明胜过AdamW。

BF16统计误差不会在(1)中新增不消失的加性误差地板，因为证明只使用A的历史可测性与上下界。这不意味着舍入不影响训练效率，且该论证不是完整浮点运算误差分析。

## 与残差压缩理论的连接

定义仅用于分析的完整能量N_t=rho N_(t-1)+(1-rho) beta(g_t-S_(t-1))^2，N_0=0。P为组内均值广播。实数运算下，q的广播值逐路径等于P N_t，包括S使用BF16预测的情形。N不需要持久保存。不能额外声称S^2+N等于普通完整梯度二阶EMA：rho与beta不同且S有舍入。

在相同历史S下，重构尺度的分母误差来自P N-N；完整压缩还会丢失S的逐坐标平方结构。因此可沿用39的局部重构误差分析，参考N须明确使用本算法实际的S。

44待检验的新增机制是：用低精度预测状态保留残差信号分解，用独立高精度更新状态保留条件无偏输入；为此将状态节省由约50%让至约25%。它不是已证实的泛化定理。

## 可声称与待验证范围

可以声称：上述算法在标准光滑非凸、无偏有限方差条件下具有平均梯度平方O(T^(-1/2))保证，不依赖残差随时间衰减或信号噪声识别准确；理论状态字节约减少25%。

不能从当前推导声称：固定噪声下统一o(T^(-1/2))、完整AdamW轨迹复杂度支配、训练/测试质量支配或墙钟支配。训练目标的平稳性也不直接保证总体风险或测试损失。较快指数需要另一个已证明能改变方差项随T变化的机制，不能通过将迭代复杂度改称token复杂度获得。

最小机制验证应将44与43、相同44但FP32统计、相同44但采用当前统计定尺度对照；前两者检验状态精度代价，最后一项检验历史尺度机制。当前只提出候选，不启动实验。

## 伪代码

Require: theta_0, eta, beta, rho, epsilon, a, H; fixed groups I_b
Initialize: S_0=0 (BF16), U_0=0 (FP32), q_0=0 (FP32)
for t=1,...,T:
    A_t <- HistoricalScale(S_(t-1), q_(t-1), t)  # formula above; A_1=I
    g_t <- stochastic_gradient(F, theta_(t-1))
    U_t <- beta U_(t-1)+(1-beta) A_t g_t
    theta_t <- theta_(t-1)-eta U_t
    q_(t,b) <- rho q_(t-1,b)+(1-rho) beta mean_(i in I_b)(g_(t,i)-S_(t-1,i))^2
    S_t <- BF16(beta S_(t-1)+(1-beta) g_t)
return theta_T

该返回值用于训练；理论的平均平稳性对应均匀抽取一个历史迭代点，并不直接声称最后一步同阶。
