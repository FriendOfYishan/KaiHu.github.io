# 候选44最终实验汇总

2026-11-16。实验目录 `experiments/20261116_candidate44`，远端 RTX 3090。全部数字来自本目录 `runs/*.json`，
汇总表见 `RESULTS_ZH.md`，核验见 `kernel_checks.json`、`math_checks.json`，冻结计划见 `FROZEN_PLAN.json`。

**结论：候选44（按笔记首配置）在本轮真实WikiText-2 Transformer与CIFAR-10上没有超过43，也没有超过AdamW。
44−43 的配对差为 +0.039 ± 0.123 NLL（不可分辨）；44−AdamW 为 +0.159 ± 0.086（AdamW 更好）。
笔记里"把统计预测器与更新动量分离"这一改动**没有**带来可测收益；被验证为真的有收益的是两件小得多的事：
BF16 统计几乎免费、以及"用历史而不是当前统计定尺度"在语言模型上大幅更好。
最重要的一条实测事实是笔记的尺度界假设与这个模型的尺度相差约三个数量级：H=1e4 在语言模型上截住了 87% 的坐标。**

## 3. 机制读出：为什么 44 约等于 43

`RESULTS_ZH.md` 的尺度读出表（每步检查点用历史状态重算 A 的分布；只统计真实参数坐标）：

|量|语言（44，末检查点）|CIFAR（44，末检查点）|
|---|---|---|
|未截断的 1/√分母中位数|2.2e4（2.19–2.26e4）|7.8e3–8.5e3|
|A 的均值 / 5% / 50% / 95%|9589 / 6.6e3 / 1e4 / 1e4|6.9e3–7.2e3 / 1.3e3 / 7.8e3 / 1e4|
|**上限 H=1e4 的饱和比例**|**87.1%–87.8%**|**22%–34%**|
|下限 a=1e-3 饱和比例|0|0|
|分母尺度 √den 的均值|6.2–6.4e-5|2.4–2.5e-4|
|**残差项 r 占分母比例**|**95.5%–95.9%**|96.5%–96.8%|
|更新 ‖U‖ 的 RMS|0.134–0.138|0.18–0.19|

三点直接结论：

1. **尺度界与模型尺度错配。** 笔记取 a=1e-3、H=1e4，并写明"满足 a≤1≤H"，即隐含 A≈O(1)。但 A 的自然尺度是
   1/√(每坐标梯度尺度)，本模型每坐标梯度尺度约 6e-5（语言）/2.5e-4（图像），于是 1/√den 的自然值是 2e4 / 8e3，
   比 1 高 3–4 个数量级。结果：**语言上 87% 的坐标被上界截住**，44 在这些坐标上退化成"固定尺度 1e4 的动量 SGD"，
   历史残差尺度机制只在 13% 的坐标上真正生效。图像上只截住 22%–34%，机制生效面大得多——这与"语言上 44−43 方向为 +0.039、
   图像上 44−43 方向为 −0.010（两者都不可分辨）"的观测方向一致，但也不能把图像的这点方向差异当成结论。
2. **残差项主导分母（95%+）。** 即 A≈1/√(组残差)，逐坐标 S 只贡献约 5%。这解释了三件事：
   (a) S 用 BF16 还是 FP32 几乎无差别（44−44-fp32 = +0.007 ± 0.013，而且 BF16 统计 30 步自由漂移只有状态 RMS 的 5.5%）；
   (b) 44 与 43 表现接近，因为两者的分母主要都由"残差能量"决定；
   (c) 44 的"逐坐标统计"在这个尺度下携带的信息很少。
3. **上界放宽反而更差。** 语言上 H 从 1e4 放到 1e5/1e6（此时 1e5 只截住 6%、1e6 完全不截），
   最优 lr 掉到网格最低点 3e-4，验证 NLL 仍比 44 差 0.12–0.13。也就是说这个截断实际起的是"绝对步长稳定器"的作用，
   而不是笔记担心的表示损失。图像上 H=1e5 与 1e6 三条种子逐位相同（该界完全不再触发），说明图像根本不需要放宽。

补充诊断：语言上 44 的训练 probe NLL 比 43 高 0.052、比 AdamW 高 0.196，而验证−probe 间隙（44 0.100、43 0.113、AdamW 0.137）
反而最小。**44 落后是"同预算下拟合不足"，不是过拟合**；这与43轮"语言模型暴露同预算优化不足"的结论一致，44 没有修好它。
（CIFAR 的训练 probe 只取 `train_ix[:4096]`，按类别拼接后偏置于第一类，43轮已记录该取样偏差，本轮不作为收敛指标。）

## 5. 修正与偏差记录

0. **启动失败一次（未产生任何训练数据）。** 第一次启动主队列时 `check44.py` 重构后漏掉 `main()` 包装，`run44.py` 在
   写任何 run 记录之前就抛出 `AttributeError` 退出；修复后重跑。`JOB_FAILED.json` 保留该记录，`runs/` 里没有被污染的数据。
1. **AdamW 日程 bug（已整组重跑）。** 第一遍实现的 `Optim.step` 没有把日程学习率写回 torch 优化器的 `param_group`，
   于是 AdamW 跑的是恒定峰值 lr、无 warmup 也无 cosine（43 与 44 的核函数直接接收 lr，不受影响）。
   该组全部作废并整组重跑（352 秒，`adamw_rerun.json`），本文件与 `RESULTS_ZH.md` 里 AdamW 的数字全部来自重跑。
   影响量级：语言验证 NLL 5.579 → 5.543，CIFAR 验证准确率 65.0% → 74.5%（选参），即第一遍会**高估** 44 相对 AdamW 的优势。
2. **网格边界。** 边界补充探针（`refine.json`）确认：语言上 44 与两档 H 组在 1e-4 都显著更差（+0.39~+0.66），
   即选到的 1e-3 / 3e-4 是真实最优而非网格造成的假最优；图像上 44 系列在 3e-4 也更差（准确率 −4.6~−5.3 pp）。
   重跑后 AdamW 的两个任务最优点都落在网格内部（语言 3e-4/1e-3/3e-3 = 5.773/5.514/6.107；CIFAR 1e-3/3e-3/1e-2 = 73.1%/74.5%/66.6%）。
   `refine.json` 里 AdamW 的两行是重跑前的陈旧值，已在 `RESULTS_ZH.md` 中过滤掉并在表下单独注明。
3. **数据重新生成。** 43 轮的原 bin 未留下生成脚本，本轮用 `prepare44.py` 重新生成并记录 sha256（见 `data/lm_manifest.json`），
   因此 43 与 AdamW 两组本轮全部重跑，跨轮数字不可直接相减；配对比较只在本轮内部做。
4. **定理假设。** 笔记的步长条件含 η ≤ 1/(4LH) 等，在 H=1e4 下要求 η 约 1e-5 量级，而本实验调出的 η=1e-3；
   H=1e5/1e6 两组差距更大。**本轮所有运行都在定理的步长条件之外**，因此本实验既不能验证也不能反驳该定理，
   只能说明"按首配置实现后在真实任务上的质量"。

## 6. 对理论文本的含义（需要改的地方）

- 第 19 行"正尺度界 a=1e-3、H=1e4，满足 a≤1≤H"：这个区间对本项目模型的**逐坐标**统计不成立（自然尺度 2e4/8e3）。
  若要保留 [1e-3,1e4] 这种"围绕 1"的写法，应把 s、r 换成无量纲量（例如相对组内梯度能量归一化），或把 H 写成
  "H = c/√(每坐标梯度能量)"并把 c 作为超参；否则首配置在语言模型上 87% 坐标退化为固定尺度。
- 第 80 行"44 的机制目标是改善统计和更新方向的分离，使该常数及实测质量改善"：本轮实测质量**没有**改善
  （44 比 43 差 +0.039 不可分辨，比 AdamW 差 +0.159 显著）。该句应改为"该分离在当前尺度与预算下未观测到质量收益"。
- 第 90 行"用低精度预测状态保留残差信号分解，用独立高精度更新状态保留条件无偏输入"：条件无偏性成立且已被本实验的
  合成核验与核函数对照支持；但"保留残差信号分解"的收益在本任务上被组残差项（95%）与上界饱和（87%）掩盖。
- 第 96 行"训练目标的平稳性也不直接保证总体风险或测试损失"：本轮支持这点——44 的验证−probe 间隙最小（0.100），
  但验证/测试 NLL 都不是最好，说明它的短板是拟合而非泛化。

## 7. 下一步最小实验建议（按信息量排序）

1. **先把尺度做无量纲**：令 A = clip( (s²+r)/Ĝ_b² )^(-1/2) 或直接 A = clip(1/√(s²+r) · Ĝ_b, a', H')，其中 Ĝ_b 是该组梯度能量的
   EMA（可复用 q 的自由量），使 A 的自然尺度回到 O(1)，再看 H 界与 BF16 统计的结论是否改变。这是本轮唯一被证实的"口径问题"。
2. **测"残差项是否真的需要逐坐标 s"**：44 的分母 95% 来自组残差，所以直接做 A_b = clip(1/√(r_b), a, H)（纯组尺度）作为对照，
   如果它与 44 不可分辨，则逐坐标 S 与 BF16 存储都可以省掉，状态回到 4d+4B，比笔记的 6d+4B 更省。
3. **CIFAR 用更长日程**（≥10 epoch）再比较：两 epoch 上七组不可分辨，结论只代表早期进度。
4. **语言用 3–4 倍预算**再比较 43/44/AdamW，并把 lr 在长预算下重新选一遍（本轮 1006 步探针沿用 503 步的 lr）。

## 9. 可以声称与不能声称

**可以声称**：在本轮 30.3M 参数、4.12M token、真实 WikiText-2 与 CIFAR-10 两 epoch 的协议下，
(1) 44 与 43 不可分辨、44 显著落后 AdamW 0.159 NLL；(2) 44 的 BF16 统计与 FP32 统计不可分辨（+0.007 ± 0.013）；
(3) 语言上"历史统计定尺度"比"当前统计定尺度"好 0.283 NLL；(4) 笔记首配置的尺度上界在语言上截住 87% 坐标、
残差项占分母 95%；(5) 放宽上界不改善质量；(6) 优化器持久状态从 8 降到 6.007 字节/参数（−24.9%），
内核更新耗时 0.50 s 对 1.23 s。
**不能声称**：算法整体优于 AdamW 或 43；O(T^-1/2) 定理被实验支持（步长条件不在范围内）；
大模型/长训练/泛化结论；墙钟优势（总训练 22.64 s 对 23.17 s 的差异未做独立重复计时）。
