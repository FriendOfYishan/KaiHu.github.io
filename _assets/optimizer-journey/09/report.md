# 多层缩减的数学核验

2026-11-08。本目录对应用户要求的“当前点梯度 + 直接动量/参数递推”探索。未使用 GPU、未新增神经网络训练。

完整结论在 [理论核验与候选筛选](../../theory/09_MULTILEVEL_SHRINK_AUDIT_ZH.md)。用户的 tilde 累加式不成立；几何相对缩减候选通过恒等式检查，但没有通过“同时更快、更低噪声”的闭环二次模型检查，不应作为已成功算法宣传。

- `verify.py`：符号变换、历史梯度平方滤波的精确方差、等价参数递推、归一化幅度界、几何尺度往返与线性混合反例。
- `results.json`：本次核验输出。iid 滤波模拟为 12,000 条链、3,000 步，输入为中心化单位方差标量，仅核对线性滤波恒等式。
- `quadratic_probe.py`：真实闭环带噪二次模型，梯度在当前 x 求取；六个方法、四个学习率、两个 beta2、512 条配对独立链、1,800 步，全部网格输出，无参数筛选。
- `quadratic_results.json`：所有闭环结果与每组尾部均方误差的跨链标准误。尾部窗口为 1301–1800 步，不把有限时间窗口均值称为精确稳态方差。

复现：在项目根目录分别运行 `python experiments/20261108_multilevel/verify.py` 与 `python experiments/20261108_multilevel/quadratic_probe.py`。依赖 numpy、sympy。程序是数学研究原型，不是可直接用于分布式或混合精度训练的优化器。

本次正面结果：变量/参数两种实现误差约 1e-15；常见相对系数线性混合可出现 1.265625 的两步历史增益，几何式在相同尺度往返中为 .81。

本次否定结果：beta2=.999 时，相对运输对噪声带改善很小，二阶缩减的噪声放大仍在；beta2=.7 时能缓和部分噪声，但代表点仍不能同时超过 Adam 与原 Shrink-v2。上一轮 PS-AdamW 的 MNIST 数据不属于本候选，不能用于本目录的性能结论。
