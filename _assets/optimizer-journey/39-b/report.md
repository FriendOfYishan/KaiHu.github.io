# 39-B补充实验结论

已完成12个200步预选、6个1000步确认运行。沿用RTX4080、5.28M参数Transformer、WikiText-2、4096000训练token、配对种子22/33/44；39-B与普通动量都独立选出LR=1.0。原AdamW、37和39结果复用同目录此前完成的相同配置运行，未冒充本次重新计时。

实现严格采用39-B最终连续强度版本，修正分母||d||²+||C||²；M平均修正后的y，q平均y−M_old的残差，旧M构造方向；缓存s。8步GPU融合实现与直接公式核对，最大绝对误差1.20e-7。

39-B相对普通动量的验证NLL配对差为[+.000134,−.004841,+.005809]，均值+.000367，3种子配对t区间[−.012871,+.013605]。没有显示稳定收益，3种子只有1个更好。测试指标同样未显示优势。

额外方向修正让优化器累计耗时比普通动量增加86.3%，总训练时间增加约1.0%。39-B与普通动量训练峰值同为621.315MiB；约50%优化器状态节省相对AdamW仍成立。普通动量共享包装器留有少量未用组缓冲，数学状态报告不含这些缓冲，实际峰值包含它们；不能将该控制描述成所有实现中最快的普通动量。

预定验证NLL≤6.0、终点仍达标的插值时间：AdamW4.621秒、Layer37为7.348秒、普通动量9.299秒、39-B为9.560秒。39-B比普通动量多约2.8%，比AdamW多约106.9%。插值基于100步检查点，不是精确首次到达测量。

本次没有独立估计S/Q和局部曲率，也没有随机轴、沿旧M轴或匹配位移范数控制。因此结果不能反驳条件下降定理，也不能证明理论条件在训练中满足；它直接说明当前39-B机制没有产生可观察的端到端优势。

本轮不支持继续增加39-B训练预算。保留上一轮H1的局部结构结果，但39-B新增的方向修正应视为未通过本次训练筛选。后续若研究，应先测真实梯度沿差异轴的信号及修正相对旧M的非共线部分，而非再调多项式或增加分母复杂度。
