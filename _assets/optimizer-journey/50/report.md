# 候选50 探针 + 混合版 50b（2026-11-21，30 分钟轮）

**结论：纯 50 在 30.3M 语言任务上一轮探针就崩了（验证 NLL 7.2024，48 是 5.60）。
按你的第 3 点做的混合版 50b（48/49 的逐坐标预条件 + 50 的精确残差预算当张量阻尼）**完全回到 48 的水平**（5.5862，3 种子）。
原因可以定量给出：50 的"精确预算" `L_t` 与更新能量 `D_t` 之比在真实训练里是 **2×10⁻¹⁰ 量级**，所以那个阻尼因子是 1−10⁻¹⁰，
数学上精确、数值上恒等于 1。**

## 1. 三个版本

|版本|方向（分子）|分母|结果|
|---|---|---|---|
|**50 纯**|`K⊙B`，`K²=(a_i²+b_j²)/2`，`a_i=(s_i+ε²)/(s_i+R_i+ε²)`|张量标量 `sqrt(D+L)`|LM **7.2024**（单种子 11）|
|**50b 混合**|48 的 `A=1/sqrt(M̂²+N̂)` 逐坐标预条件|`Z·(1+L/D)^{-1/2}`（只加 50 的预算阻尼）|LM **5.5862**（3 种子），CIFAR **72.62%**|
|48（上一轮）|同左|`A`（无张量阻尼）|LM 5.5967（2 种子），CIFAR 72.74%|

同种子配对（22/33）：50b 5.5791 对 48 5.5967 → **50b 好 0.018（种子噪声内）**；对 AdamW 5.5401 → 50b 差 0.039。
CIFAR 三种子：50b 72.62% 对 48 72.74%、AdamW 72.85% → 全部在 0.3 pp 内。
状态：50/50b 都是 **4.01 字节/参数**（与 48 相同，AdamW 的一半）。

## 2. 为什么纯 50 会崩、50b 却是空的

纯 50 的实际更新是 `U = (K⊙B)/sqrt(D+L)`，其中 `K ≤ 1` 且 `K ≈ s/(s+R)`——这是"残差相对信号越大、增益越小"的**收缩**。
在真实语言模型里 `R ≫ s` 对绝大多数坐标成立，于是 `K` 把几乎所有坐标的分子压小，
而分母只是一个张量标量，**补不回逐坐标的信号尺度**。结果就是整体欠步：7.20（连 Layer37 的 5.98 都不如）。
这与 39–45 一路得到的教训一致：张量/块级标量配不上逐坐标的分母。

50b 把 50 的作用降级成"只用一个张量阻尼 `(1+L/D)^{-1/2}` 去乘 48 的更新"，于是它的效果完全取决于 `L/D`。
我在真实模型上直接测了 20 步：

|步|Σ L|Σ D|L/D|
|---:|---:|---:|---:|
|2|0|25,843|0|
|5|1.1e-6|25,905|4.3e-11|
|10|2.9e-6|25,990|1.1e-10|
|20|5.8e-6|26,162|**2.2e-10**|

原因是代数的：`a_i ≈ s_i/R_i`（残差主导时），于是 `R_i a_i² ≈ s_i²/R_i ≪ s_i ≈ D`。
**50 的精确抵消恒等式（式 1）是对的，但它"精确预算"的那个量相对于要调的更新本身小了十个数量级**，
所以作为阻尼器没有可测作用。这也解释了 50b 与 48 的结果逐项重合。

## 3. 裁定

- **纯 50：实战失败**（语言 +1.6 NLL、连 Layer37 区间都没到），原因是增益形式把逐坐标尺度换成了行列标量收缩。
- **50 的数学亮点（式 1）成立但操作上为空**：`L/D ~ 1e-10`，阻尼不可测。这个恒等式更适合当**诊断量/上界证明**，
  不适合当控制量。若要保留它，只应以 50b 的形式：**方向用 48/49 的逐坐标预条件，预算只作为理论保证/监控**。
- **50/50b 都没有超过 AdamW**（语言差约 0.04–0.05，CIFAR 同量级）。这与 47/48 轮结论一致：
  在这条"行列残差压缩"路线上，48 已经是最强的形态，再改分母/增益都不会有质量增量。
- 如果目标仍是"超过 AdamW"，本工作区四任务实测里唯一稳定领先的是 **Muon / SOAP**（语言 −0.40 / −0.13，CIFAR +11.3 pp / +2.5 pp，
  扩散/视频同样领先）。把 48 的行列结构与 Muon 的动量矩阵几何结合才是下一步，而不是继续改分母。
