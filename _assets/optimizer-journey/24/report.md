# Joint-AWA 对齐界对照

完整实验分析与条件优势证明见 [理论24](../../theory/24_ALIGNMENT_BOUND_COMPARISON_ZH.md)。

两轮共2880个由原Joint-AWA产生的固定状态，三类低维任务；每个状态精确枚举当前4种梯度结果。没有修改优化器，没有新增GPU训练。第二轮使用全新种子8–15，补测第23版已有的有界方向协方差修正。

确认子集720个状态，真实期望下降527个。各界证实下降数：旧Young32、Cauchy347、已知方差敏感度300、未知方差创新替代234、有界方向修正366。零错误下降证书；但修正界仅40%状态比Cauchy更紧，不能声称全面更准确。

![界对照](range_refinement/bound_comparison.png)

另证明：标量历史均值准确且0<sigma<a|phi(mu)|/(2H)时，新敏感度对齐界严格优于Cauchy，证书差值至少eta[a sigma |phi(mu)|-2H sigma^2]。构造核验600例，其中条件内360例全部通过。该结论是界优势，不是新更新优势。

当前决定：保留Joint-AWA，不因诊断改善就加入逐坐标控制器。未知噪声方差和历史偏差仍是主要障碍。
