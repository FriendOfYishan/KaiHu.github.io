# 候选46：公式核查 + 修正 + 短对比（2026-11-18）

结论先说：**你的公式有 4 处必须改的问题；改完（46a）它是这一族里最差的一个（比 AdamW 差 0.186）；
我按实测教训改出的 46b 也只是追到 43 与 AdamW 之间（比 AdamW 差 0.042，区间跨 0）。
两版都不建议继续，更不该上 GPT-2。**

## 1. 逐条核查

|编号|原式|问题|数值证据（`mathcheck46.json`）|改法|
|---|---|---|---|---|
|E1|`g_t = ∇_θ ℓ(g_{t-1}; ξ_t)`|对 `g_{t-1}` 求导，应为参数|—|`g_t = ∇_θ ℓ(θ_{t-1}; ξ_t)`|
|E2|`e_t = |g_t − m_t|`|**恒等于 `β·|g_t − m_{t-1}|`**：这是同一条残差乘 0.9，不是新量；而且让它依赖当前梯度|最大相对误差 1.2e-7|`e_t = |g_t − m_{t-1}|`（旧动量）|
|E3|`r_t = ρq_{t-1} + (1−ρ)βe_t`，`q_{t-1} = (1/d)Σr_i`|两者互为定义（自指/错位）；且 `u_t` 用 `r_t`，分母依赖当前梯度|ρ=0.999 时分母随当前梯度的相对变化只有 0.27%（结构错、数量级小）|先有 `q_{t-1}`，分母用它；参数更新后再算 `q_t`|
|E4|`r` 的逐坐标部分|**每步被组均值 `q` 重新锚定**，坐标差异只剩 `(1−ρ)βe_i`|坐标变异系数：字面 0.0017 对普通逐坐标 EMA 0.025 → **只剩 6.7%**，等价于一个组标量|要么用组标量（4d+4B），要么做真正的逐坐标 EMA|
|E5|`u = m/(|m|+r)`|在中等信噪比严格小于 Adam 的 `m/√(m²+r²)`（|m|=r 时 0.5 对 0.707）|本轮 46a 的实测正是最差|换成 `√(m²+scale²)` 形状（见 46b）|
|E6|`θ = (1−λη)θ − ηu`|λ 未给值|—|本轮对比协议 λ=0；要正则化需单独调 λ|

另外两条**不是错误**、可以保留：`|u| ≤ 1` 逐坐标成立（含 r=0，最大 1.0，首步 ≈ sign(g₁)，与 Adam 同量级）；
时间常数只比标准残差慢 23%（1235 步对 1000 步），不影响结论。

## 2. 修正后的公式（46a，状态 4d+4B）

```
g_t = ∇_θ ℓ(θ_{t-1}; ξ_t)
m_t = β m_{t-1} + (1-β) g_t
e_t = |g_t - m_{t-1}|                     # 旧动量
u_t = m_t / (|m_t| + q_{t-1,b} + ε)       # 分母只用历史统计
θ_t = θ_{t-1} - η_t u_t                   # λ=0
q_{t,b} = ρ q_{t-1,b} + (1-ρ)  mean_{i∈b} e_{t,i}    # 参数更新之后再更新
```

## 3. 改进版（46b）：把三条实测教训装进去

```
g_t = ∇_θ ℓ(θ_{t-1}; ξ_t)
m_t = β m_{t-1} + (1-β) g_t
e_t = |g_t - m_{t-1}|
s_t = ρ s_{t-1} + (1-ρ) e_t ,  s_hat = s_t/(1-ρ^t)          # 逐坐标 L1 噪声，带偏差修正
u_t = clip( m_t / sqrt(m_t² + (c·s_hat_t)²), ±τ ) , c=√(π/2), τ=4
θ_t = θ_{t-1} - η_t u_t
```

三条改动各有实测依据：逐坐标而不是组标量（44 轮：组尺度输 0.159）；`√(m²+scale²)` 而不是 `|m|+scale`
（45 轮：保守形状在欠训练区制欠步）；τ=4 的加速档（45 轮短预算 −0.087 的来源）。
代价：状态 8d（s 必须 FP32——长跑实测提醒 BF16 累加不了 0.999 的 EMA；若要 6d 得把 ρ 降到 0.9）。

## 5. 怎么读这个结果

1. **46a 是这一族里最差的**：组标量 + 更保守的形状 → 欠步最严重（+0.186 对 AdamW，区间下界 +0.03，不是噪声）。
2. **46b 追到了 43 与 AdamW 之间**：点估计比 43 好 0.081、比 AdamW 差 0.042；4 个种子下这两个差都还没被分辨。
   它没有超过 AdamW，也没超过 45。
3. **这个区制是对这族最有利的**（503 步 / 0.14 token每参数，45 就是在这里赢 AdamW 0.0002、赢 43 0.123）。
   连这里都只是追平，说明"换分母对象"这条路已经到顶（与 45 长跑 3.28 亿 token 输 0.018 一致）。
4. 唯一值得留的东西：**L1 残差作为尺度是可行的**（46b 与 45 差 0.042，同量级，且不需要逐坐标平方/开方），
   如果将来做低状态版本，L1+ρ=0.9+偏差修正可以把 6 字节存下来；但这只解决显存，不解决质量。

## 6. 建议

- **不要**在 46 这条线上继续，也不要上 GPT-2：46a 明确更差，46b 只是追平一个已经在大预算输 0.018 的 45。
- 如果目标仍是"超过 AdamW"，本工作区已有的证据指向**方向**而不是分母：短预算同 harness 里
  Muon 5.031 / SOAP 5.076 对 AdamW 5.204（43 轮）。下一步应该在那里做，而且先在 1 亿参数/3 亿 token 档拿到胜绩再谈规模。
- 如果目标是"省显存"，唯一还站得住的结论是：**m 存 BF16 + v 留 FP32 = 6 字节/参数（−25%）**，
  因为 BF16 能累加 β=0.9 的量（误差 0.27%）但不能累加 β=0.999 的量（偏差 2.71 倍，已实测）。
