# 实验结论：支持跟踪规律，尚未支持泛化优势

完成原max日程160次、补充纯幂律96次，共256次训练、8448次全训练集梯度探测。实际设备MTT S4000。新任务为Wisconsin乳腺癌分类，固定训练/验证/测试341/114/114；测试未用于选择指数。原协议与补充协议分开保存。

主结果：原日程四个r下有两组网格最小跟踪误差落在2r/3，纯幂律有三组。此为有限网格上的均值最小位置，不是唯一最优性证明；p=.2还位于扫描边界。两轮种子不同，不能把两轮差异全归因于max保护。

纯幂律在r=.5/.6/.75时，理论指数的跟踪MSE约低75%/88%/80%；r=.3时反而为EMA的5.12倍。固定EMA的噪声底结论要求持续存在非零噪声，本任务接近拟合时噪声会下降，因此不能直接套用那个反例来预测真实排名。

重要反例：纯幂律理论点的测试损失在四个r下均高于固定EMA，准确率均低于EMA。该观察只描述此小测试集和固定参数；不宣称普遍排序，但足以拒绝“降低跟踪误差必然改善泛化”的推论。最优验证损失的位置也没有沿理论线一致移动。

## 计算成本与局限

每次1024次小批量梯度=32768样本梯度，33次完整训练集梯度=11253样本梯度，总44021；研究诊断增加34.3%的样本梯度预算。原max日程平均训练3.157秒、诊断0.127秒；纯幂律平均训练3.165秒、诊断0.166秒，后者还测了批噪声与探测点间梯度变化。训练时间排除初始化与数据索引准备，诊断时间包含验证及终点测试前向。新日程本身没有增加梯度调用；直接测量跟踪误差的研究过程有成本。

原max日程p=.6/.8/1在1024步完全相同，已逐种子核对；因此补充纯幂律。补充日程首步alpha=1、其后.1*t^(-p)，较大p会很慢地遗忘初始梯度，不能把其失败完全归因于稳态误差项。c与初始学习率只固定了一个值，没有证明充分调参的最优性能，也没有本轮标准AdamW对照。EMA为同权两矩(alpha=.1)，用于隔离记忆。

配对bootstrap仅条件于固定数据划分、5或3个种子，区间未多重校正；最优网格位置还有选择偏差。机器可读区间见paired_tracking.json，不宜用3种子区间作强显著性主张。

## 对理论与后续机制的判断

支持把p=2r/3保留为梯度跟踪的起点；尚不能把它提升为普遍最优权重或泛化规律。有限步oracle给出常数修正p_T≈2r/3+log(σ²c³/(4d²))/(3logT)，详细推导见theory/19_FINITE_HORIZON_TRACKING_SCAN_ZH.md。该式是外生规则漂移模型下的主导项近似，不能当成真实训练的已校准预测器。

下一阶段应固定启动机制，测量并独立校准真实梯度漂移、噪声和梯度范数，再检验由这些量预测的权重；同时约束优化进展，而非单独最小化跟踪误差。需要同种子对照max与pure，并增加更小p和独立划分，才能确认最优区域。当前结果不足以据此发布“优于AdamW的新优化器”的结论。
