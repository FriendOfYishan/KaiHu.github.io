# PS-AdamW：简洁数学机制与短时 MNIST 验证

2026-11-08。按“新数学为主，短 toy 辅助”的范围完成。用户租用的 RTX 4090 D 上，含 MNIST 下载和所有对照，49 次运行共 **106.014 秒**；任务正常结束，结束后 GPU 显存占用为 0 MiB，没有留下后台训练。

## 观察与结论

**前移递推显著改善了原 Shrink-v2；耦合缩减的额外收益目前较弱。** 相较 AdamW，PS-AdamW 在相同梯度预算下的平均最终训练 loss 低 18.6%、全程训练 loss AUC 低 10.9%。但当前实现耗时高 51.0%，参数更新 RMS 的 P99 高 11.0%，所以本次没有实现“全面更快、更稳、成本更低”。

相较 Shrink-v2，PS-AdamW 的训练 loss 低 24.5%，更新 RMS 的 P99 低 9.8%。相较 Predict-only，PS-AdamW 的 AUC 低 1.8%，但最终训练 loss 高 1.0%、测试 loss 高 1.1%、更新 P99 高 23.7%。这里百分比是三种子均值的比值，不是显著性检验或普遍性能保证。

理论的明确增量是：同一系数既控制平方差缩减，又产生曲率相关阻尼；冻结二次模型可精确算出一个同时加快收缩、降低稳态方差的非空区间，同时给出平坦方向失败的反例。它不等同于完整自适应神经网络收敛定理。[理论与证明](../../theory/08_SIMPLE_PREDICTIVE_SHRINK_ZH.md)。

## 实验设置与成本

- 官方真实 MNIST：训练集固定随机取 12,000，子集种子 42；测试集取官方测试集前 2,000，测试集不选参数。
- 网络：784→128→10，Tanh，无 BatchNorm、Dropout；FP32，禁用 TF32。设备 RTX 4090 D，PyTorch 2.8.0+cu128，Python 3.12.3。
- 每次 300 次更新，batch 128，有放回采样。每方法每次恰好 38,400 个训练样本梯度；每 25 步在完整训练子集评估一次。
- 所有方法使用相同的四点学习率网格 `[0.0003, 0.001, 0.003, 0.01]`；只用种子 101 的训练 loss AUC 选择。28 次调参，然后在配对种子 11、22、33 上评估 21 次。配对方法同初始化、同批次序列。共享的 β=(.9,.999)，解耦权重衰减 .01。
- PS-AdamW 的缩减/预测系数均预设 .5，没有搜索系数。所有方法都只搜索学习率，其他专属超参数未做同等完整调优。
- **AdamW、Shrink-v2、Predict-only、PS-AdamW、MARS-approx 都选中学习率网格的上边界 .01。** 因而这不是充分调参后的优劣判定；按短实验要求没有继续扩大搜索。
- 计时逐步 CUDA 同步，包含前向、反向、优化器和 PS 的临时参数保存/恢复；排除评估、诊断、批次索引生成。它是训练核心计时，不是端到端流水线总耗时。毫秒级小网络中解释器与参数读写占比很高。
- 参数更新 RMS 是本步全部参数真实位移（含衰减）的均方根；P99 在排除前 20 步后计算。它衡量位移尾部，不是有效学习率抖动、方向方差或稳态噪声方差的替代证据。
- `peak_allocated_mb` 包含驻留数据、模型和公共诊断临时张量，不代表优化器独占显存。PS 持久状态只有 m,v，但前移/恢复需要临时参数副本。

## 实际比较的七种方法

|名称|本次精确定义|
|---|---|
|AdamW|PyTorch AdamW，foreach=False，eps=1e-8|
|Shrink-v2|用户 v2 的历史偏差修正动量平方混合，λ=.5，采样点不前移|
|Predict-only|标准 AdamW 二阶矩，使用理论式 (1) 的前移采样，预测系数 .5|
|PS-AdamW / Coupled|平方差缩减和前移预测均用 .5；从原参数 x 更新|
|AdaMomentum-W|[论文 Algorithm 1](https://arxiv.org/html/2106.11514v3) 对当前原始动量平方做二阶 EMA，每步在 v 中加 eps=1e-16；按该算法偏差修正，并额外采用解耦衰减|
|AdamS-paper|[论文 Algorithm 1](https://arxiv.org/html/2505.16363v1)，ν=.999 m_prev²+.001 g²，原始动量，无偏差修正，eps=1e-8，解耦衰减|
|MARS-approx|[论文近似版本](https://arxiv.org/html/2411.10438v3)，γ=.025，使用上批梯度，c=g+.225(g−g_prev)，c 的全局范数裁剪到 1 后进入 AdamW；不是同批两点精确 MARS|

没有将未运行的 SVRG、SPIDER、PAGE、STORM 等算作本次基线；本次根据用户的短 toy 范围只覆盖相关方法与必要消融。

## 可精确核验的理论机制

在固定预条件器的一维二次模型里，有效惯性由 β 变成 β−λs。给定 β=.9、λ=.5、参考有效步长 u、给定分母尺度增益 r=√2，存在区间 `0.0587167 < u < 0.5234380`，其中联合内核同时有更小的谱半径和更小的稳态参数方差。这个增益 r 是模型给定量，未证明真实 Adam 预条件器会达到它。

取 u=.2，参考方差 .100529，耦合 .059054；收缩半径分别 .948683 和 .870964。取 u=.001，耦合噪声方差反而更高。固定非零噪声和固定学习率下，这里证明的是有限噪声带与初始影响消失，不是随机迭代逐点收敛到最优解。

![冻结二次模型的精确值及有效区间](quadratic_mechanism.png)

绿色区域是上述同时改进的充分区间。该图展示解析值，不是 MNIST 或大模型的实测加速曲线。

数值核验包括：符号 Yule–Walker 恒等式、离散 Lyapunov 解、四个内核各 20,000 条独立链的 1,800 步模拟、稳定边界两侧、平坦方向反例、零系数精确退化为 AdamW、每步只调用一次 closure、梯度确实在 y 求取而衰减/更新从 x 出发。比较区间的二次多项式还通过符号恒等式和 1,000 个内部点交叉核验。记录在 [mechanism.json](mechanism.json)、[region_verification.json](region_verification.json)。

## 对论文方向的判断

这轮应保留的是“平方差缩减与曲率阻尼如何配对”的可检验理论问题。前移梯度属于已有广义 Nesterov 思想；不能单凭改名或绑一个系数就宣称首创。[EMA-Nesterov](https://arxiv.org/html/2605.25395v1) 等相关工作仍需公式级系统比较。

目前没有完整自适应非凸收敛定理，没有噪声带内长期网络训练证据，没有大模型效果，也没有实现墙钟成本优势。最关键的未解问题是证明随时间变化的分母下，缩减带来的步长增益何时能被递推阻尼有效补偿，同时解释耦合相较只预测的额外贡献。这比增加更多门控更接近本次“大而至简”的研究目标。
