# Layer38 合成稀有 token 实验（机制隔离，非 Transformer）

目的只有一个：在**可控**的语言模型里隔离"每层一个标量"的分配效应，看它能否在同等 token 预算下复现 37 在 WikiText-2 上观察到的 +0.18 NLL 差距，以及 sign（b=0）/量化形状（b=4、b=8）能否收回。

**这不是 Transformer 实验，不能替代 `20261114_layer38/PLAN_ZH.md` 的真机对照。**

## 设置

- 词表 V=2048，潜在语义维 k=16；首 token 按 Zipf(1.1) 采样；转移 logits = `W z_i + log q`，其中 q 为 Zipf(1.1) 边缘，故**目标 token 的边缘真的是 Zipf**（`ziptarget` 版）。
- 模型：tied embedding d=64 + 1 个 Transformer block（4 头、FFN 256）；batch 32 × seq 32 = 1024 token/步；400 步 ≈ 0.41M token；种子 22/33/44；调参种子 11、150 步、每臂 5 个学习率。
- 优化器：`adamw`（8 字节/参数）、`layer`（u=m + 信任比，4 字节/参数）、`sign`（b=0，u=sign μ，4 字节/参数）、`q4`（b=4/span40，4.5 字节/参数）、`q8`（b=8/span40，5 字节/参数）。全部 K=8、Kq=1、τ=1、tv=4、wd=1e-2、clip norm 1、warmup 20 + cosine 到 10%。
- 数据诊断：测试集目标 token 在四个 Zipf rank 四分位的占比为 88.2% / 6.1% / 3.4% / 2.3%；**真实条件分布的下界（floor）= 5.0639 nats**，均匀预测 = 7.6246 nats，即 2.56 nats 的可学空间。

## 读出（三条，其中一条否证了本稿原来的强主张）

1. **隔离模型没有复现 +0.18。** 这里 `layer`−`adamw` 的测试差只有 +0.0074（训练差 +0.0118），而真机是 +0.173。也就是说**"每层一个标量"的分配效应在这个只含 tied embedding + 1 层的模型里是真的但小 20~25 倍**，不足以单独解释真机差距。38 的 §5.1 分配命题作为数学命题仍然成立（`verify_38.py` E 段：>4000 步 vs 19 步），但它**不是真机 +0.18 的充分解释**。真机差距还需要别的原因（4 层堆叠、attention/LayerNorm 参数、权重衰减与 h 律的耦合、或 37 的梯度 RMS 尺度律本身）。本实验不能裁决，必须由真机分臂对照来定。
2. **`sign` 是最划算的一档。** +0.0018 的代价换 −50.0% 状态，且实现上最省（无二阶、无 log）。`q4`/`q8` 反而比 `sign` 差 +0.001，同时 clip_frac=2.4%，说明 **span=40 仍不足**：按 5.2 节，饱和会把 κ 重新引入，实测吻合。下一轮应把 b=8 的 span 提到 ≥64 并重测。
3. **频率四分位不能直接当判据，而且方向与直觉相反。** `layer` 在 Q4 反而比 adamw 好 −0.438，但它在 Q1 差 +0.025；由于 Q1 占 88% 的 token，净差仍是正的。机制：稀有输出行初始 logits≈0（预测≈均匀 4.9e-4），而 rank-2000 的真值≈1.4e-5，所以**最优行为是把稀有行压下去**；adamw 的逐坐标归一化放大了这些小梯度、压得很狠，`layer` 份额小、压得少。于是 Q4 的原始交叉熵反映的是过抑制/欠抑制，不是"谁更会学稀有 token"——这是欠抑制在极稀有行上占了便宜。**所以"改善是否集中在稀有四分位"必须先配平整体拟合**（在同一验证 NLL 处插值比较），否则会把欠拟合/欠抑制读成泛化优势。`PLAN_ZH.md` 的 A2 已据此改写。

4. **预注册的 A5/P6 只成立一半。** 原判据是"q4 的 clip_frac>1e-3 且稀有四分位劣于 q8"。前者成立（0.0241 vs 0.0245），后者**不成立**：q4 在 Q4 略优于 q8（10.1974 vs 10.2072），整体两者只差 0.00003（5.09887 vs 5.09890）。结合两者的 κ_q 分别是 2.15 与 1.09，结论是：**在这个尺度上，位宽（b=4 vs b=8）不可分辨，可分辨的是 span（饱和）**。因此推荐配置从"b=8/span32"改为"b=4/宽 span"（0.5 字节/参数，−43.75%）——但这条只在合成模型上测过，真机仍需复测。

5. 两处与 PLAN 的偏离已记录：(i) 五个臂都用 `tv=4`（PLAN 要求 `L38-layer` 用 `tv=None`）；(ii) `q4`/`q8` 用 span=40 而非 PLAN 写的 16/32。前者使 `layer` 臂的尺度律与本族一致（更干净的消融），后者是修正后的推荐值。真机执行时以 `PLAN_ZH.md` 为准。

另外两条实现事实：参考实现里 `q4`/`q8` 的优化器耗时是 adamw 的 3.2 倍（2.9 s vs 0.9 s），因为 Kq=1 且每步做 log₂；这正是 38 §5.3 说的"必须用实现 B（整数对数域加性更新）"的理由，不能拿参考实现的耗时去反对或支持算法本身。`layer`/`sign` 的 0.48/0.50 s 比 adamw 的 0.90 s 快 1.8 倍。

状态字节与 (12) 的预测逐字节吻合：4n / 4.5n / 5n / 8n（n=181 184），相对 AdamW −50.0% / −43.75% / −37.5% / 0。

## 一个被丢弃的初版 law（记录为负面结果）

最初的生成器用 `softmax(W z_i)` 且无 `log q` 项，实测 logit 标准差只有 0.25，转移行几乎均匀：四分位各占 25%，真实条件分布的 floor 是 7.5917，均匀预测 7.6246，**可学空间只有 0.0329 nats**。该 law 下五个臂的差异全在 0.003 nats 以内，什么也测不出（`rare_token_runs.csv` 保留）。任何"机制缺失"的合成实验都必须先报出 floor 与均匀预测之间的可学空间，否则数字没有意义——这条应写进后续所有合成实验的预检。
