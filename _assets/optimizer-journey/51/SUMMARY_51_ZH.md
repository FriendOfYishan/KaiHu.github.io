# 候选51：四任务实测（2026-11-21，30 分钟轮）

**结论：51 是这一系列（39→51）里第一个在语言任务上超过 AdamW 的候选——同一 lr（1e-3，也是两者各自的最优点）下
验证 NLL 比 AdamW 低 0.060，三个种子逐个都低（−0.0619 / −0.0546 / −0.0621，配对 95% 半宽 ±0.010）。
图像、扩散、视频三个任务与 AdamW 打平。状态仍是 4.01 字节/参数（AdamW 的一半）。
语言上仍落后 Muon（+0.33）和 SOAP（+0.06）。**

## 1. 51 是什么（一句话）

把更新拆成两项：**历史方向**用 48 的逐坐标尺度（`P=B⁻/sqrt((B⁻)²+Ñ+ε²)`，`|P|≤1`），
**本步新信息**用 50 的平方可加增益 `K²=0.5/(v⁰+ε²)+0.25/(v_r+ε²)+0.25/(v_c+ε²)` 乘 `ω(G−B⁻)` 并截断到 ±2：

```
U = P + clip( ω·K⊙(G − B⁻), −2, +2 ),   ω=(1−β)/(1−β^t)
```

关键是 K 有一个**与历史信噪比无关的下限** `K ≥ 1/sqrt(2(v⁰+ε²))`：
即使某个坐标历史动量为零，当前梯度也至少以 `ω/sqrt(2v⁰)` 的斜率进入更新；而截断 ±2 保证单点尖峰不会拖累整张量。

## 4. 为什么这次能超过 AdamW（机制读法）

前面几轮的失败模式很清楚：43/44/45 只用"归一化增量的动量"，初始化后 EMA 把每步压到 0.1–0.3 倍；
48 换成逐坐标预条件但仍只沿动量方向走；49 把分母改成信号加权、把步子放大，反而更差。
**51 第一次给"本步梯度本身"留了一个有下限、有上限的直接通道**：

- 下限 `K ≥ 1/sqrt(2(v⁰+ε²))` 让新信息不会因为历史动量为零而被吞掉（这正是 48 在低动量坐标上的失血点）；
- 上限（±2 截断加上 `|P|≤1`，使 `|U|≤3`）保证它不会像 45/49 那样把步子放大到失衡；
- 残差压缩误差只留在历史方向 P 里，新信息那部分的预算由 (4) 式精确给出、与行列重构无关——这也正是 50 的代数亮点被用对了地方。

用一句话说：**历史动量负责稳定、当前梯度负责信息，两者分开定尺度，比任何"只用一个通道"的版本都好。**

## 5. 判据与限制

- 语言上的 −0.060 是三种子一致、同 lr、同数据顺序的配对结果；但只有 3 个种子、单任务单预算（4.12M token），
  不能宣称大模型或收敛结论。
- 51 仍落后 Muon 0.33、SOAP 0.06：**它不是本 harness 里最好的优化器**，只是这条残差压缩路线里第一个赢 AdamW 的。
- 未做：真实 1 亿参数/3 亿 token 预算（45 轮的长跑格式）、51 的 ±2 截断与 K 下限系数的消融、
  截断触发率与截断能量占比的记录（note 里点名要这两个诊断）。
- 状态 4.01 B/参数已复核（`state_bytes/parameters`），峰值显存与 48 相同（3285 MiB 对 AdamW 3401）。

## 6. 建议下一步（按信息量）

1. **先把消融补齐**（半小时级）：`51` vs `51 无下限（K 去掉 1/sqrt(v⁰) 项）` vs `51 无截断` vs `51 只用 P（=48）`。
   这能证明"下限 + 截断"是收益来源，而不是又一个巧合。
2. **换到长预算**（45 轮的 1 亿参数/3.3 亿 token 格式）：45 在那里输 0.018，若 51 在长预算仍赢 AdamW 0.05 以上，
   才值得谈规模。
3. 与 Muon/SOAP 的差距（0.33/0.06）说明"方向"仍是更大的杠杆；51 的"双通道"思想可以叠加到 Muon 的动量矩阵几何上。
