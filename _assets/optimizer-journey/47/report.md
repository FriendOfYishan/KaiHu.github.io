# 候选47 / 候选48 四任务对照：最终汇报（2026-11-20）

**一句话：48 站住了——四个任务上与 AdamW 同量级（语言 +0.057 ± 0.042，其余三任务统计无差），
状态只有 AdamW 的一半（4.01 vs 8.00 字节/参数），语言上还小幅赢过 Adafactor；
但它没有超过 AdamW，且在这个 harness 里 Muon/SOAP 全面领先。
47 在四个任务上全部垫底且幅度极大（语言 +1.39 NLL、图像测试准确率 40.7% 对 72.8%、扩散 3.4 倍 MSE、视频 6.2 倍 MSE），
它的组内中心化投影是根本性的损伤，不是调参问题。**

## 1. 做了什么

八组（`AdamW`、`Adafactor`、`Lion`、`Muon`、`SOAP`、`Layer37`、`47`、`48`）× 四任务（语言、图像、扩散、视频），
同一套 harness、同种子逐 batch 相同数据顺序、同日程（warmup+cosine 到 0.1、裁剪 1、零权重衰减、BF16 前后向 + FP32 主权重）。
每方法按自身量纲给 2 个学习率选参（种子 11），再用选中值跑种子 22/33；47 的 τ 另扫 {1e-4, 1e-2}。
共 293 个原始运行，队列 53.5 分钟（含之后的 47 重跑约 10 分钟）。

|任务|模型 / 数据|预算|主指标|
|---|---|---|---|
|语言|30.3M Transformer、WikiText-2|503 步 = 4.12M token|验证 NLL|
|图像|ResNet18、CIFAR-10|2 epoch（352 步）|测试准确率|
|扩散|DDPM、CIFAR-10 32×32、小 U-Net|600 步|验证噪声 MSE|
|视频|MovingCIFAR 下一帧预测（Conv3D）|500 步|验证 MSE|

## 3. 候选 48 的裁定（按预注册判据）

- **A1（vs Adafactor，note 自己定的对标）**：语言 5.5967 对 5.6728（**48 更好 0.076**）；图像 72.74% 对 73.09%（−0.35 pp）；
  扩散 0.04522 对 0.04100（48 差 0.0042）；视频 0.00919 对 0.00868（48 差 0.0005）。
  **裁定：语言上达到并小幅超过对标，其余三任务与 Adafactor 同量级但不占优。**
- **A2（vs AdamW）**：语言 +0.0566 ± 0.0422（区间 [+0.014, +0.099]，点估计在 AdamW 之后但幅度只有 1%）；
  其余三任务统计无差。**裁定：48 是"AdamW 同量级 + 状态减半"，不是超过。**
- **状态账**：48 = 4.01–4.06 字节/参数（M 4 + 行/列 0.01），AdamW 8.00 → **省约 50%**，与 note 的账一致。峰值显存也低 3%（3284 对 3401 MiB）。
- **耗时（未融合 torch 实现）**：语言 30 s 对 24 s、图像 17 对 13、扩散 17 对 8、视频 22 对 21。
  **48 现在比 AdamW 慢**，差距全部来自逐步的行/列归约与额外的中间张量；要谈速度必须写融合核（与 45 的结论相同）。

## 4. 候选 47 的裁定

- **A3**：四个任务全部垫底，且不是"小幅落后"：语言 +1.39 NLL、图像测试准确率 40.7%（几乎只学到 40%）、
  扩散 3.4 倍 MSE、视频 6.2 倍 MSE。**组内 8 坐标的"减均值"投影是硬约束：参数永远不能沿这些方向移动
  （16384×768 的 embedding 每行就冻结 96 个方向，每个线性层每行冻结 12.5% 的方向），在真实模型上代价远大于它想省下的噪声。**
- **A4（计数机制）**：在语言任务上跑 200 步的探测（同一数据顺序）测得

|τ|q 均值（200 步后）|h 均值|h 最小|第 200 步 loss|
|---|---:|---:|---:|---:|
|1e-6|170.7|0.088|0.071|7.816|
|1e-5|112.9|0.205|0.071|7.797|
|1e-4|28.8|0.410|0.072|7.637|
|1e-2|0.0008|0.9999|0.255|7.068|

  即：**τ 小于 ~1e-4 时几乎每个坐标每步都超阈，q 线性增长、h 按 1/√t 塌陷（200 步后只剩 0.09–0.41 倍步长）；
  τ=1e-2 时计数几乎不触发，h≡1，47 退化成"中心化动量 SGD"（loss 7.07，仍远差于 AdamW 的 5.54）。**
  全局固定 τ 与逐坐标梯度量纲（~1e-4）之间没有可用的工作点——这正是 48 note 第 3 条批评的那一点，本轮给出了定量证据。
  所以 47 的两次选参都落在 τ=1e-2（计数失效档），这是"两害相权"而不是机制在起作用。

## 5. 修正记录（必须说明）

**47 的第一次实现有 bug**：我把"超阈坐标比例"误写成"块内残差绝对值均值"，于是 τ 完全不生效
（初版在语言上四个 τ 给出逐位相同的 q 与 loss，暴露了这一点）。修正后
（`cand>=tau` 的计数）单元检查确认 τ 生效（5 步后 q：τ=1e-6 → 5.00，1e-4 → 4.996，1e-2 → 4.09），
并删除了 48 个旧 47 运行、四个任务全部重跑。上表 47 的数字全部来自修正后的实现。

## 6. 结论与建议

1. **48 可以留**：它兑现了"状态减半、质量不掉"的承诺（三任务无差、语言 1% 之差），并且在语言上赢过 Adafactor。
   下一步值得做的只有两件事：写融合核把逐步开销降到 AdamW 以下（目前更慢），以及做 note 里的 RMS 裁剪消融。
   它**不应**被宣传成"超过 AdamW"的算法。
2. **47 建议放弃**：投影造成的信号损失是结构性的（q/τ 的工作点分析已经说明计数机制无法在不塌陷步长的情况下生效），
   这不是换超参能修的。它自己的 note 也写了"目前不给 47 安排 30M"，本轮四任务数据支持这个判断。
3. **如果要"超过 AdamW"**：这个 harness 里 Muon（语言 −0.40、图像 +11.3 pp、扩散 −0.0085、视频 −0.0015）和
   SOAP（视频第一、其余第二）才是赢家。把 48 的"残差行列分解"与 Muon 的"动量矩阵几何"结合，比继续在分母上做文章更可能出结果——
   这也与本工作区 45 轮长跑得出的结论一致（对角线分母路线已经到顶）。
4. **四任务的一致性**：Muon/SOAP 在四个任务上都在前二，48 在四个任务上都紧跟 AdamW，47 在四个任务上都垫底。
   这种一致性说明本轮 harness 的排序是稳的（虽然每格只有 2 个种子）。
