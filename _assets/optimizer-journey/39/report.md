# 四项实验的结论与解释

全部完成：RTX4080，5.28M参数四层Transformer，WikiText-2，1000步/4096000训练token，配对种子22/33/44。共有42个200步预选、21个主确认、6个同学习率补充消融；另有固定快照轨迹诊断和GPU微基准。主配置在200步预选后冻结，补充消融不取代它。

## 实验一：固定梯度轨迹支持H1

在本轮三个AdamW训练后快照上冻结参数，重放同一64批梯度，主统计窗口33—64步。每种子7组、32步，残差压缩在224/224组步比较中均得到更小局部代理误差。累计残差/完整压缩误差比分别为0.08703、0.08584、0.10569，减少约89.4%—91.4%。这些组步不是独立种子，不能当672个独立训练实验。

统计量从零初始化，以免h1=1对应的均匀初始残差掩盖实际结构；与训练初始化的差别已明确记录。完整逐路径矩恒等式最大误差约8.01e-11。此结果验证真实梯度轨迹上的局部代理误差收益，没有测实际单步独立损失收益，不构成AdamW或泛化优势证明。

## 实验二：多项式逼近成立，未显示同学习率下的系统性质量损失

固定轨迹最大逐坐标绝对逼近误差0.082693，满足1/12≈0.083333的界。训练消融结果：

|共同学习率|多项式验证NLL|精确版验证NLL|配对均值差poly−exact|
|---|---:|---:|---:|
|.01|5.37558|5.41648|−.04090|
|.03|5.77095|5.79775|−.02680|

配对差样本SD分别.06995/.07650；仅3种子，没有建立统计非劣或严格优势。不能因为独立调优组中poly(.03)比exact(.01)差，就把差距归因于多项式函数。

独立GPU微基准中，poly为.07130ms/步，exact为.07405ms/步，仅约3.7%差异；完整训练主运行poly和exact的优化器累计耗时也很接近。去掉逐坐标开方没有带来数量级的额外加速。

|AdamW-fused / Flat-AdamW|5.18987±.02244|5.19107|
|Layer37|5.35679±.00652|5.34956|
|Layer-no-budget|5.35620±.00166|5.35013|
|39-poly主配置，LR=.03|5.77095±.05070|5.75352|
|39-exact主配置，LR=.01|5.41648±.05142|5.40480|
|Full39-exact，完整残差参考|5.58177±.01555|5.57103|
|39-poly补充共同LR=.01|5.37558±.05439|见原始消融记录|

主poly相对AdamW验证差+.58108，3种子配对t区间[+.40200,+.76016]；相对Layer37差+.41416，[+.30287,+.52544]。补充poly(.01)的质量明显优于主配置，但仍未追平AdamW，也未显示超过原37的稳定收益。

200步预选偏向poly(.03)，而1000步共同LR消融显示.01更适合长日程。这是明确的选参日程敏感性。补充结果应单列，不能事后将它包装成事先选定的赢家。

完整残差参考也没有追平AdamW，说明本轮差距不能只归因于压缩。参考使用β1=β2=.9、未偏差校正、初始残差1−ε²和延迟残差；AdamW预选选择β2=.999且有标准偏差校正。归一化、时间尺度和初始化共同改变了优化行为，本实验没有把这些因素逐一消融。

## 实验四：低状态和低更新开销成立，同质量总时间不成立

主poly相对标准AdamW：状态40.285→20.145MiB，减少49.995%；完整训练峰值641.433→621.295MiB，减少3.14%。1000步优化器累计耗时1.17145→.39278秒，减少66.5%；整段训练20.300→19.008秒，减少6.37%，但验证质量更差。

Flat-AdamW达到相同Adam质量，总训练18.969秒，与poly的19.008秒基本相当。不能把相对多张量标准Adam的部分调度收益都解释为算法优势。

预先固定目标验证NLL≤6.0，要求终点保持达标：

|方法|达到目标的平均训练时间|
|---|---:|
|AdamW-fused|4.621秒|
|Flat-AdamW-fused|4.332秒|
|Layer37|7.348秒|
|39-exact(.01)|6.893秒|
|39-poly主配置(.03)|11.673秒|
|39-poly补充消融(.01)|6.778秒|

主配置需要标准Adam的2.53倍时间；补充.01配置仍多46.7%。这些是100步验证点间插值，不是毫秒精确的首次到达测量。

## 本轮裁决

保留“残差压缩比完整二阶量压缩更接近完整参考”的局部结构结论。多项式是本轮可用的低成本函数逼近，尚没有证据表明它本身是训练质量差距的主要原因。

39作为完整训练配方未达到同token或同质量总时间目标，不应据本轮结果直接扩展到更大的训练预算。下一项研究若继续，应解决完整参考本身与强AdamW的优化行为差距，以及短预选与长日程的不匹配；不能继续以代理误差更小代替端到端优势。
